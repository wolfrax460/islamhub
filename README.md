# 🌙 Islamic Knowledge Hub

**A beautiful, free, offline-first Islamic educational website**  
**Quran • Hadith • Duas • Pillars of Islam • Key Concepts • Advanced Studies • Audio Lectures**

Fully bilingual (English & Kinyarwanda) with dark/light mode and perfect mobile support.

---

## ✨ Features

- ✅ Authentic Islamic content from trusted sources only
- ✅ Full **English ↔ Kinyarwanda** language switch (one click)
- ✅ Beautiful **Dark / Light Mode** toggle
- ✅ 100% **Responsive** — looks perfect on phones, tablets & desktops
- ✅ Fast search bar
- ✅ Modern Islamic UI with smooth animations and glassmorphism effects
- ✅ Advanced Studies section with direct links to thousands of free PDFs (EmaanLibrary, Kalamullah, etc.)
- ✅ Recommended audio lecture platforms
- ✅ Works completely **offline** (single HTML file)
- ✅ No backend, no tracking, no ads — pure dawah project

## 🚀 How to Use

1. Download the project
2. Open `index.html` in any browser (Chrome, Firefox, Safari, etc.)
3. No installation required!

**Language Switch:**
- Click the **"Kinyarwanda" / "English"** button in the top right
- All text updates instantly

**Dark Mode:**
- Click the moon/sun button

---

## 🛠️ Setup & Hosting (Free)

### Option 1: GitHub Pages (Recommended)
1. Create a new GitHub repository
2. Upload the `index.html` file
3. Go to **Settings → Pages → Source → Deploy from branch → main**
4. Your site will be live at `https://yourusername.github.io/repo-name`

### Option 2: Netlify / Vercel / Cloudflare Pages
Just drag & drop the `index.html` file.
